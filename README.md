# Thaumic Horizons — Forge 1.12.2

Current unfinished port sources and compiled JARs. Development stopped. This is not a finished gameplay release.

TH sources: `output/ports/thaumichorizons/`. Related TC4 and Forbidden Magic sources are included. Built JARs are in `artifacts/`.

Build environment: JDK 8, Gradle 4.10.3, ForgeGradle 2.3.4, Forge 1.12.2-14.23.5.2847, stable_39 mappings. Building requires TC4 dev/API and Baubles 1.12.2 dependencies in TH `libs/`, plus the Forge/Gradle dependency environment. Original upstream ownership and existing license terms remain unchanged.
